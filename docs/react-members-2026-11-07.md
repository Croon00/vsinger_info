# Re:AcT 미졸업 멤버 등록 (2026-11-07)

이 문서는 최초 등록 시점의 기록이다. 이후 사용자 요청으로 신규 16개 채널의
수집을 활성화하고 과거 영상 수집을 시작했다. 현재 진행 범위와 실행 로그는
[영상 수집 기록](react-collection-2026-11-07.md)을 따른다.

사용자가 요청한 20명을 [공식 공개 소속 명단](https://www.v-react.com/)과 대조하고,
공식 사이트의 멤버별 YouTube 링크를 YouTube channels API로 확인한 뒤 신규 카탈로그에 반영했다.
등록 입력과 멤버별 출처는 [seed](../data/seeds/react_members_2026_11_07.json)에 보존했다.

- 기존 4명 유지: 칸나기 안나, 안야 쿠모리, 우스와 스우, 시시가미 레오나.
- 신규 16명: 유메카와 카나우, 미즈가메 미아, 마루모치 츠키미, 네코노 유키노,
  츠쿠시 아리아, 스메라기 로제, 마코우 리사, 오토기 네무, 시라네 유키,
  레이라 사마, 스즈하나 이노리, 오토하 소라, 시라즈나 이오, 토묘지 카구라,
  코토토이, 아야모 노노.
- 공식 명단의 졸업 표기 멤버 花鋏キョウ, 九楽ライ, ククルア・クレイユ는 입력에서 제외했다.
  공개 명단에는 없고 HTML에 과거 팝업만 남아 있는 天川はの도 포함하지 않았다.
  기존 졸업 멤버 데이터를 삭제하거나 소속을 변경하지 않았다.
- 레이라 사마는 활동 휴지 상태이며 미졸업 명단에 포함했다.

## 반영과 검증

기존 `scripts/register_requested_vsingers.py`에 이번 seed를 `--seed`로 전달했다.
읽기 전용 dry-run 후 `--apply`로 한 transaction에 적용했다.
감사 영수증은 `catalog_imports.id=7758`이며 기존 도구의 정책명
`requested-vsingers-2026-10-03-registration-v1`을 사용한다.
변경 48건은 아티스트 16건(ID 1024–1039), YouTube 계정 16건(ID 340–355),
owner 연결 16건이다.

2026-11-07 실데이터 검증: 20명 전원의 한글·원어 이름, Re:AcT 소속,
카탈로그 표시, 공식 채널 ID와 owner 연결을 확인했다.
신규 16개 계정의 `collection_enabled=false`를 확인했다.
동일 입력으로 등록 함수를 재실행한 transaction은 `no_changes`, 변경 0건을
확인한 뒤 롤백했다. 코드 변경은 없으며 fixture 테스트 실행 기록은 아니다.

이번 반영은 아티스트와 공식 YouTube 연결 등록이다. 신규 음악 수집 작업,
재수집, Discord 전송은 요청하거나 실행하지 않았다. 기존 4명의 수집 설정은 유지했다.
X URL은 출처로 seed에 보존했으며 수집 계정으로 등록하지 않았다.
데뷔일, Spotify·Apple Music 계정, 추가 과거 YouTube 채널은 변경하지 않았다.
