# 곡 탐색 — 2026-11-01

탐색의 아티스트/곡 탭은 URL `view=artists|songs`로 전환한다. 곡 탭은 우타와꾸 곡·커버 곡·오리지널 곡을 제공하며 소속사, 정렬, 곡 이름 검색, 24개씩 더보기를 지원한다. URL의 `kind`, `song_agency`, `song_order`, `song_q`로 선택을 보존한다. 아티스트 탐색의 검색·정렬 값과 분리한다.

## 표시와 집계

VESPERBELL·KMNZ 커버는 사용자 지정 [공유 채널과 멤버 표시](shared-youtube-channels.md)를 적용한다. 멤버 이름 검색에는 명시적 솔로·협업·미표기 합창 구분을 사용하며 전체 곡 목록에서는 같은 영상을 한 번만 표시한다.

- 우타와꾸는 확인된 `song_id`별로 묶는다. 미연결 곡은 정규화한 원문 곡명+원곡 아티스트 키로만 묶으며, 동일 제목만으로 서로 다른 작품을 합치지 않는다. 원곡 아티스트 이름을 확인된 곡 명의 또는 원문에서 얻을 수 없는 묶음은 목록에서 제외한다. 가창 횟수는 `DISTINCT performances.id`다. 복수 가창자 때문에 같은 공연을 중복 집계하지 않는다. 가창자 명의가 없을 때만 라이브의 대표 아티스트를 사용한다. 소속사는 가창자의 현재 등록 소속사로 필터한 뒤 집계한다. 리스트 열기는 곡 고유 키와 소속사를 유지해 홈 검색과 같은 세트리스트 화면으로 이동한다.
- 커버는 영상 한 개당 한 항목이다. 제목에 명시된 cover/covered/covers·歌ってみた·カバー·커버를 근거로 사용하고 설명만의 홍보 문구나 歌唱 크레딧은 분류 근거로 사용하지 않는다. 셀프 커버도 제외한다. 과거 오분류 후보를 삭제하지 않고 동일 제목 기준으로 조회에서 제외한다. 소속사 범위는 업로드 공식 채널의 현재 owner 관계다. 채널 소유자가 곧 확정된 가창자라는 뜻은 아니며 임의로 참여자를 생성하지 않는다.
- 오리지널 탭은 현재 등록된 발매 음원(`recordings`)을 버전별로 표시한다. 여러 앨범에 수록돼도 동일 recording은 한 항목이다. 공식 영상이 `covers`에 있고 현재 제목 기준으로도 커버인 항목만 제외한다. 과거 설명만으로 만들어진 cover 후보 때문에 정상 발매 음원을 숨기지 않는다. 나머지 발매곡의 커버 여부는 모두 검수된 상태가 아니므로 화면에 미확정 곡 포함 안내를 표시한다. 소속사는 등록된 발매 아티스트를 따른다.
- 보관 처리된 아티스트·공연·영상·곡은 각 조회에서 제외한다. 영상은 공개·일부공개·미확인 상태를 허용한다. YouTube 링크가 없는 발매곡도 목록에 남기며 조회수는 `—`로 표시한다.

우타와꾸 기본 정렬은 부른 횟수 내림차순이며 오름차순·최근 부른 순·곡 이름 순을 지원한다. 커버·오리지널 기본은 YouTube 조회수 내림차순이며 오름차순·최신 영상 순·곡 이름 순을 지원한다. 조회수 미확인은 양방향 모두 마지막이다. 동률은 곡 제목과 고유 키로 결정한다. 최신 영상 정렬은 연결된 YouTube 영상의 게시일이며 발매일 정렬로 표기하지 않는다.

## HTTP 계약

커버·오리지널 곡 제목은 연결된 YouTube 영상이 있으면 현재 화면의 Dialog에서 재생한다. 모바일 inline 재생과 autoplay를 요청하며, 원문 YouTube 링크도 유지한다. 제목과 아티스트를 표시하고 닫기·Escape·배경 클릭으로 닫을 수 있다. 닫거나 탐색 조건을 바꾸거나 페이지에서 벗어나면 iframe을 제거해 재생을 중단한다. 영상 미연결 제목은 재생 버튼으로 만들지 않는다. 자동 재생 허용 여부와 퍼가기 가능 여부는 브라우저·YouTube 정책을 따른다.

2026-11-01 실제 모드 빌드와 PC·모바일 모달 테스트 4개를 통과했다. 모달 테스트는 YouTube iframe 응답을 fixture로 대체하고 동영상 ID·자동 재생 파라미터·페이지 유지·닫기/ESC 후 플레이어 제거·포커스 복귀·다른 곡 전환·영상 미연결 처리를 검증했다. 실제 YouTube 음성 재생 검증과는 구분한다.

`GET /api/explore/songs?kind=utawaku&agency=all&q=&order=high&offset=0&limit=24`

`kind=utawaku|cover|original`, `order=high|low|latest|name`, `agency=all|independent|소속사 원어명`이다. `q`는 최대 200자이며 원어·한국어 곡명과 아티스트 원어·한국어·영문 이름 및 별칭을 부분 검색한다. 우타와꾸는 부른 아티스트와 확인된 원곡 가수, 커버는 공식 채널 소유 아티스트, 발매곡은 등록된 가창 명의에 적용한다. 검색어와 일치하는 곡을 찾되 곡별 횟수는 소속사 범위 전체 집계다. SQL wildcard 문자는 리터럴로 처리한다. `offset`은 0~100000, `limit`은 1~100이다. 기존 조회 API와 동일하게 API_KEY 설정 환경에서만 키를 요구한다. 잘못된 열거값·범위는 422다. 임시 `/api/v2` 별칭에서도 제공한다.

`GET /api/explore/song-performers?song_key=song:1&agency=all`은 해당 곡의 전체 부른 아티스트를 `id,name,display_name`으로 제공한다. 첫 세트리스트 페이지에 없는 아티스트도 선택할 수 있다. `/search` 화면은 기존 행·썸네일·영상 시점 이동을 재사용하며 `/api/search`에 `song_key`, 선택한 `artist_id`, `agency`를 전달해 페이지 계산 전에 필터한다. 홈의 일반 검색 동작은 유지한다.

## Shorts 제외

곡 탐색과 아티스트 커버 탭은 동일한 Shorts 표시 규칙을 사용한다. 명시적인 Shorts 제목 표식 및 저장된 `is_short=true` 항목은 제외한다. 180초 초과 영상 또는 일반 영상으로 확인된 항목을 표시하며, 180초 이하·길이 미확인 항목은 형식 확인 전까지 대기한다. 길이만으로 짧은 일반 커버를 Shorts라고 확정하거나 원본을 삭제하지 않는다. 화면에 대기 정책을 안내한다.

```powershell
.venv\Scripts\python.exe scripts/classify_youtube_cover_formats.py
```

형식 확인은 신규 DB의 기존 커버 중 대상 최대 10,000개를 조사한다. 제목 표식은 먼저 저장하고, 나머지는 YouTube robots.txt 허용 여부를 검사한 뒤 공개 `/shorts/{video_id}` URL에 HEAD 요청을 보낸다. 해당 URL의 HTML 200 응답은 Shorts, 같은 영상 `/watch?v=`로의 리디렉션은 일반 영상으로 기록한다. 동의·알 수 없는 리디렉션은 미확인으로 보존한다. 403·429·서버 오류는 중단하며 CAPTCHA·로그인·차단을 우회하지 않는다. 요청 간 1초 이상 쉬고 영상·음성·player API·비공개 browse API를 요청하지 않는다.

현재 YouTube 공개 URL 동작에 의존하는 판별이며 YouTube Data API의 공식 Shorts 플래그는 아니다. `collection_states.provider_state.youtube_video_formats`에 영상 ID별 판별·근거·확인일만 저장한다. 다른 namespace를 보존하고 20개 단위로 저장해 재실행 시 완료 대상을 건너뛴다. 미확인은 24시간 후 다시 확인할 수 있다. 초기 분류는 백그라운드에서 진행하며 PC·프로세스 종료 시 같은 명령으로 재개한다.

`Page[SongExploreRead]`는 `items,total,offset,limit`를 제공한다. 항목은 `key,title,title_ko,artist_name,youtube_video_id,view_count,views_updated_at,performance_count,artist_count,archive_id,start_seconds,published_at`이다. 해당되지 않거나 확인되지 않은 수치는 null이다. 조회는 읽기 전용이며 provider·LLM·Discord·Calendar를 호출하지 않는다.

## 조회수 갱신

```powershell
.venv\Scripts\python.exe scripts/refresh_youtube_video_statistics.py
```

신규 DB identity 검증 후 기존 커버 또는 발매 음원에 연결된 YouTube 영상 중 업로드 source 계정이 있고 최근 24시간 안에 갱신하지 않은 영상을 최대 10,000개 선택한다. `videos.list(part=snippet,statistics)`를 최대 50개씩 최소 2초 간격으로 호출한다. 한 실행은 최대 200개 API 요청이다. 채널 ID가 기존 업로드 계정과 같은 응답만 저장하며 기존 소유권을 변경하지 않는다.

Pydantic으로 검증한 `view_count`, `channel_id`, `captured_at`을 기존 collection state의 `youtube_video_statistics` namespace에 영상 ID별로 저장한다. 다른 namespace·lease·cursor는 유지한다. 페이지 단위 트랜잭션이며 재실행은 24시간 안의 완료 항목을 건너뛴다. 실패한 요청은 무제한 재시도하지 않고 안전한 원인 코드로 종료한다. 키·DB URL은 출력하지 않는다. 신규 수집 영상이 늘면 같은 명령을 다시 실행해 미확인 조회수를 보충한다. 주기적 자동 갱신 작업은 이번 변경에서 등록하지 않았다.

기존 source 계정이 없는 영상과 API에서 반환되지 않는 영상은 수치를 추정하거나 다른 계정에 귀속시키지 않는다. YouTube 조회수와 확인일을 함께 표시하며 실시간 수치로 안내하지 않는다. Spotify 재생 수는 사용하지 않는다.

## 우타와꾸 리스트의 복수 가창자·방송 날짜 필터

리스트 열기와 홈 검색의 `/search` 화면에서 부른 아티스트를 여러 명 선택할 수 있다. 선택한 가창자 중 누구라도 포함된 가창 기록을 합집합으로 조회하며 협업 가창은 중복 반환하지 않는다. 아무도 선택하지 않거나 '부른 아티스트 전체'를 선택하면 가창자 제한을 해제한다. 기존 상세 통계에서 전달하는 단일 `artist_id` 범위와 `song_key`·소속사 범위는 유지한다.

`GET /api/search`에 반복 `artist_ids=1&artist_ids=2`(양의 정수 최대 100개), `start=YYYY-MM-DD`, `end=YYYY-MM-DD`를 지원한다. 기존 `artist_id`와 함께 전달하면 해당 범위와 복수 선택의 교집합이다. 날짜는 `COALESCE(live_archives.broadcast_at,videos.published_at)`의 한국 시간 날짜로 비교하며 양 끝 날짜를 포함한다. 시작일 또는 종료일만 지정할 수도 있다. 역전된 범위·잘못된 날짜·잘못된 ID는 422다. 이 조건은 정렬·총 개수·페이지 계산 전에 적용한다. 영상 등록일을 사용하는 커버/오리지널 날짜 표시와 구분한다.

곡 키가 없는 홈 검색에서도 첫 50건에 한정되지 않은 가창자 선택지를 제공하도록 `GET /api/search/performers?q=...&agency=all&artist_id=...`를 추가했다. 기존 검색과 같은 제목·별칭·원곡자·가창자 일치 범위에서 활성 공개 아티스트를 중복 없이 반환하며 페이지 제한이 없다. 선택한 가창자와 날짜 필터로 선택지 자체를 줄이지 않는다. 곡 키가 있으면 기존 `/api/explore/song-performers`를 사용한다. 두 경로 모두 기존 API 키 정책을 따른다. 조회는 외부 수집을 시작하지 않는다.

화면 URL의 반복 `artist_ids`, `start`, `end`에 필터를 보존한다. 빈 결과에서도 조건 변경·초기화가 가능하며 잘못된 날짜 범위는 요청 전에 안내한다. 원곡 아티스트 선택은 기존처럼 현재 불러온 결과에 적용하는 단일 필터다.
