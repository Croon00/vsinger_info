# 오리지널 곡 가사 독음과 번역 반영

2026-11-26 사용자 요청에 따라 대화에서 직접 한글 독음과 한국어 번역을 작성했다. 프로젝트 OpenAI API는 이 반영에 사용하지 않았다.

- 대상은 기존 오리지널 가사 원문 608개와 녹음 662건이다. 승인 파일의 녹음 ID, 저장 원문, 출처 URL을 대조하고 보관 녹음과 발매 커버를 제외했다.
- 원문이 짧은 곡부터 처리하고, 이후에는 같은 가사를 공유하는 녹음 수를 함께 고려했다. 중복을 제외한 원문 43개에서 1,196줄을 작성해 녹음 63건의 빈 `pronunciation_ko`와 `translation_ko`를 채웠다. 원문, 출처, 줄 순서와 빈 줄을 보존했다.
- `ラピスのお人形`, `Dreamscape`, `リスポーン!!`에는 제작진 명단 또는 감상 댓글이 저장돼 있어 보류했다. `食虫植物`과 `夜が降り止む前に`의 안내·감상 문장 한 줄씩은 원문에 두고 해당 줄의 독음과 번역을 비웠다.
- 작성 묶음과 처리 상태는 Git에서 제외된 `db-migration/reports/original-lyrics-2026-11-25/`의 `direct-01.txt`~`direct-06.txt` 및 `annotations.sqlite3`에 보존했다.

## 실데이터 검증

- 2026-11-26 신규 통합 DB에서 반영한 63건을 다시 읽어 작성본과 일치하는지, 원문 줄 번호에 독음과 번역이 대응하는지 확인했다.
