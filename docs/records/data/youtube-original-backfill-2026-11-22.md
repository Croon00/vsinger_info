# YouTube 오리지널 누락곡 보완 기록

2026-11-22 사용자 요청으로 신규 카탈로그에 반영했다. legacy DB·Discord·Calendar·OpenAI는 사용하거나 변경하지 않았다. 이 작업은 명시적 과거 보완이며 일일 worker 배포/활성화와 다르다.

## 조사와 반영

공개 아티스트 또는 공개 멤버가 속한 그룹의 수집 활성 공식 owner 계정 138개를 조사했다. 기존 전체 목록 캐시와 최신 uploads 갱신을 합쳐 73,489개 업로드를 확인했고 채널·영상 상세 API 요청 799회를 사용했다. provider quota 오류는 없었다. 전체 캐시 재사용으로 매번 전 채널 과거 목록을 다시 받지 않는다. 캐시 역사 목록에만 남은 삭제/이름 변경을 모두 실시간 재검증했다는 의미는 아니다.

신규 녹음 **40곡**, 기존 녹음의 공식 영상 연결 **14건**, 합계 **54건**, 가창 명의 **21개**에 반영했다. shin `Reboot of Mine`, Figaro `彗星の夜明け` 2곡은 공식 채널·가창 크레딧·발매 안내를 직접 검토한 제한 manifest로 등록했다(감사 10472). 짧은 홍보/축약 영상 9건은 이번 작업의 생성 감사·외부 영상 ID·미수정 상태를 확인해 가역적으로 보관 처리했다(10473). 기존 등록 음원·영상·명의는 삭제하거나 병합하지 않았다.

실행 결과와 원문은 `outputs/original-backfill-2026-11-22/`의 channels/details/results, `applied-audit.json`, `reviewed-manifest.json`, `verified-db.json`에 남겼다. 실제 반영은 worker lease·snapshot·동일 트랜잭션 claim/persist 및 catalog_imports/catalog_changes를 사용했다. 일반 후보 검토 결과는 로컬 결과 파일이며 모두 DB에 등록한 것은 아니다.

## 남은 범위

**모든 영상이 오리지널로 확정된 것은 아니다.** 자동 판정 보류 3,292건에는 일반 영상·커버·기존 공식 영상 보존·가창 명의 불명·협업·홍보 영상이 섞여 있다. 이 숫자는 누락된 오리지널 곡 수가 아니다. 비활성 계정·미등록 별도 유통 채널·타인 채널만의 발매·삭제/비공개 영상은 이 조사의 완전성 범위에 들지 않는다.

스크린샷의 渚沢シチ(983)는 본인 채널 562개 업로드에서 이번 기준에 맞는 본편 오리지널을 확인하지 못했다. 화면은 곡 목록으로 개편했지만 해당 아티스트에 없는 곡을 만들지는 않았다. Figaro(941), shin(942) 화면에서 신규 반영 곡을 확인할 수 있다.

## 규칙 보완과 검증

정확한 오리지널 곡 태그·복합 Vocal 크레딧·그룹 명의 표기를 지원한다. `Original MV/オリジナルMV`만으로 원곡 창작 근거를 확정하지 않는다. 짧은 영상(90초 미만/길이 미상), short.ver·1Chorus·일본어 티저/홍보 표기는 자동 등록하지 않고 별도 검토한다. 실제 짧은 완성곡도 이 보수적 경로에서는 별도 검토 대상이다.

관련 Python 회귀 83 passed, 44 skipped(disposable PostgreSQL 바이너리 부재). 실제 원격 DB 반영·감사 재조회와 fixture 검증은 별개다. 로컬 프론트·API HTTP 200과 신규 곡 목록 반영을 확인했다. 일일 worker 배포와 생략한 DB fixture는 [012 작업](../../../specs/012-youtube-original-daily/tasks.md)에 남긴다.
