# 곡 월드컵 8강 검증

2026-11-27 오리지널과 커버의 규모 선택에 8강을 추가했다. 후보가 8~15곡이면 8강만 선택할 수 있고, 기본 규모는 32강이다. 8강은 8강전 4경기, 4강전 2경기, 결승 1경기를 끝내면 제출한다. 종류별 랭킹 집계는 기존 쿼리를 사용한다.

- `pytest tests/test_worldcup.py` 16개와 Vitest 월드컵 단위 테스트 13개 통과. 제출 fixture로 오리지널·커버 8강을 검증했다.
- Playwright 데스크톱·모바일 4개 통과. 오리지널 8강 선택과 커버 8강 완료 후 7경기 제출을 확인했다. Vue 타입 검사와 운영 빌드도 통과했다.
- 로컬 PostgreSQL 실행 파일이 없어 마이그레이션 테스트는 20개 건너뛰었다. 별도의 메모리 PGlite에서 같은 SQL을 실행했다. `008`에서 거부되던 8강이 `009` 적용 후 두 종류 모두 7경기와 함께 저장됐고, 기존 16강 기록이 보존되며 4강 제출은 거부되는 것을 확인했다.
- 운영 적용은 8강 지원 백엔드 배포, `009` 적용과 검증, 웹 배포 순서로 진행한다.
