# YouTube 커버 변경·검증 기록

현재 계약은 [YouTube 커버 영상](../../youtube-covers.md)을 따른다. 2026-11-23 현재 문서에서 날짜별 절을 옮겼다. 수치와 상태는 각 기록 시점의 값이다.

## 2026-10-31 최초 구현 검증

- 프론트엔드 실제 모드 빌드 통과, 기존 단위 테스트 48개 통과.
- HTTP fixture를 사용하는 PC·모바일 브라우저 테스트 4개 통과: 탭 지연 조회, 더보기, 원문 URL, 새로고침 후 선택 유지, 오류 재시도, 빈 목록, 가로 넘침 검사.
- provider/DB mock을 사용하는 요청 예산·체크포인트 재개 테스트 2개 통과. 로컬 PostgreSQL 바이너리가 없어 폐기 가능한 DB를 사용하는 신규 API·저장 테스트 2개와 기존 카탈로그 읽기 테스트 13개는 건너뛰었다.
- 별도의 실데이터 검증에서 신규 DB identity, 수집 활성 채널 95개, 기존 커버 380개를 확인한 뒤 요청된 추가 수집을 실행했다. 실제 페이지 저장을 확인하고 신규 DB를 읽는 FastAPI TestClient에서 아티스트별 조회 200, API 키 설정 시 미인증 401, 없는 아티스트 404, 잘못된 페이지 크기 422 및 페이지 간 ID 중복 없음을 확인했다. 전체 채널 수집 완료 여부는 체크포인트의 `done`과 실행 로그로 확인해야 하며 테스트 통과와 구분한다.

## 2026-11-01 오분류 수정 (v2)

설명의 歌唱 크레딧과 커버 홍보 문구로 원본 MV가 후보에 포함된 것을 확인하고 제목 기반 v2로 제한했다. 분류·수집·조회 회귀 테스트 40개 통과, 로컬 PostgreSQL이 필요한 41개는 건너뛰었다. 실제 로컬 API에서 `NDOJZSG9SPU`(花譜 #36 不可解)와 `UKZt1vq8bKI`(シリウスの心臓 원본 MV)가 커버에서 제외되고, 후자의 연결 발매곡이 오리지널 탭에 노출되는 것을 확인했다. 원본 데이터·소유권은 변경하지 않았다. 이전 연결 오류로 중단된 과거 수집도 같은 체크포인트에서 새 규칙으로 재개했으며 기존 24시간 요청 예산은 유지한다.

## 2026-11-01 프리미어 누락 보정 (v3)

`QOCmDcgPtYw`는 공개된 236초 커버인데 방송 시작·종료 metadata 때문에 미수집된 것을 API로 확인했다. 완료된 명시적 커버를 허용하도록 v3를 적용하고 VESPERBELL의 기존 계정 소유권으로 저장했다. 실제 로컬 API에서 조회수 5,633,058회, 요미 포함·카스카 제외를 확인했다. 두 공유 채널 27페이지 재검사를 완료해 같은 원인의 커버 80개를 추가로 복구했고, 조회수 80개와 짧은 영상 형식 2개도 확인했다. 지정 영상의 직접 추가 1건은 이 80개와 별개다. YouTube Data API의 공식 premiere 플래그로 판정한 것은 아니며 완료 상태와 명시적 커버 제목을 사용하는 규칙이다.

## 2026-11-01 별도 게시 채널 커버 복구

추가 전체 대조에서 공유 채널 업로드 목록에 나타나는 별도 게시 채널 ID의 커버가 동일 채널 필터에 제외된 문제를 발견했다. 정확한 출처 ID를 승인 목록·신규 external account에 등록해 누락 267개를 복구했다. 출처 미연결 상태의 기존 완료 프리미어는 빈 출처만 채우고 기존 라이브 행을 보존하며 커버로도 조회한다. 임의의 다른 채널은 수집하지 않으며 기존 출처를 덮어쓰지 않는다. 전체 대조·멤버 배정·조회수 검증은 [공유 채널 기록](shared-youtube-channels-history.md)에 있다.
