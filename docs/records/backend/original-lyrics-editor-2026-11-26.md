# 오리지널 곡 가사 등록과 수정

2026-11-26 곡 탐색과 아티스트의 오리지널 곡 탭에 가사 등록·수정 모달을 구현했다. 기존 가사를 수정할 때는 서버에서 최신 버전을 불러온다. 저장은 해당 녹음 한 건을 대상으로 하며, 다른 편집이 먼저 저장되면 409를 반환한다. 한글 발음·한국어 번역·출처 URL을 선택해 입력한다.

## 검증

- 별도 편집 키와 입력 형식을 포함한 백엔드 회귀 테스트 30개 통과. 일반 PostgreSQL 바이너리가 필요한 테스트 1개는 건너뛰었으며, 같은 시나리오는 격리 PGlite 데이터베이스에서 통과했다. 마이그레이션을 적용한 합성 데이터로 최초 등록, 기존 가사 수정, 변경 이력과 원출처 보존, 같은 입력의 재요청, 발매 커버와 보관 가사 차단, 오래된 버전 응답을 확인했다.
- 웹 단위 테스트 78개와 프로덕션 빌드 통과. 데스크톱·모바일 HTTP fixture 4개에서 기존 가사 조회·재생 패널, 영상 없는 곡의 등록, 키 오류 시 입력 보존, 저장 후 버튼 변경과 포커스 복귀, 두 목록을 오가는 가사 수정과 조회를 확인했다.
- 설정된 통합 DB를 로컬 API에서 읽어 최신 오리지널 24항목의 대표 녹음 ID와 기존 가사 1건의 버전 응답을 확인했다. 이 DB의 가사 등록·수정은 시험하지 않았다.
- 운영 배포와 편집 키 설정이 남았다. 구현한 계약과 설정 절차는 [가사 등록](../../original-lyrics.md#웹에서-등록수정)에 있다.
