# 쿠로쿠모 등록·영상 수집 (2026-11-07)

사용자가 지정한 [공식 YouTube 채널](https://www.youtube.com/channel/UCtOy6aKyz2ltSKSkQccXVGA)을
YouTube channels API로 확인하고 신규 카탈로그에 등록했다.
입력은 [seed](../data/seeds/kurokumo_2026_11_07.json)에 보존했다.
이름은 くろくも / 쿠로쿠모 / Kurokumo이며, 소속은 미확인으로 비워두었다.

- 아티스트 ID 1040, YouTube 계정 ID 356, 단일 owner 연결.
- 기존 등록 도구로 3건 생성. 계정 수집 활성화 영수증은 7776.
- `collection_enabled=true`. 구독자 수·채널 생성일 통계 갱신 완료.
- API 통계의 공개 영상 수는 177개였고, 업로드 목록은 4페이지·178개를 끝까지 확인했다.
  provider의 통계 수와 목록 수가 다르므로 같은 값으로 취급하지 않는다.

## 과거 영상 반영

`backfill_catalog_youtube_covers.py --account-id 356`으로 이번 계정만 수집했다.
4페이지를 끝까지 처리해 커버 138개를 저장했다. 원문 설명·출처를 보존했다.
Shorts 제목 표식 18개와 짧은 영상 31개의 공개 Shorts URL을 기존 도구로 확인했다.
2026-11-07 검증 시 현재 조회 계약상 표시 가능한 일반 커버는 107개다.
Shorts·판정 미확정 영상은 기존 조회 규칙을 따른다.

공개 목록의 노래 방송 후보 6개는 `kurokumo-2026-11-07` 요청으로 작업
131572–131577에 등록하고 기존 worker로 실행했다. 초기 작업 6건 모두 성공했지만,
이는 모든 영상의 세트리스트 추출 완료를 뜻하지 않는다.
실데이터 조회로 방송 5개, 가창 행 36개를 확인했다.
그중 세트리스트가 있는 방송은 3개이며 다른 2개는 `unprocessed` 상태다.
댓글 대기 1개와 세트리스트 판정 재시도 2개는 후속 작업
131578–131580으로 예약되어 있다. 원본 영상·기존 소유권을 변경하지 않았다.

즉시 수집을 실행한 임시 worker는 종료했다. 후속 작업과 이후 채널 poll은
활성화된 계정에 대해 운영 음악 worker가 처리해야 한다.
로컬 `.env`의 `RUNTIME_CUTOVER_ENABLED`와 `AGENT_ENABLED`는 false였으며 변경하지 않았다.
수집 명령에만 프로세스 환경변수를 사용했다. 조회 API만 실행해서는 worker가 시작되지 않는다.
이번 실행에서 Discord·Calendar는 호출하지 않았다.

## 이어서 실행

프로젝트 루트의 PowerShell에서 이번 요청만 이어서 처리할 수 있다.
플래그는 해당 PowerShell 프로세스 환경에 적용된다.

```powershell
$env:RUNTIME_CUTOVER_ENABLED='true'
$env:AGENT_ENABLED='true'
.\.venv\Scripts\python.exe scripts/backfill_requested_utawaku.py worker --seed data/seeds/kurokumo_2026_11_07.json --reports db-migration/reports/kurokumo-2026-11-07 --request-run kurokumo-2026-11-07
```

2026-11-07 검증 범위: 실제 provider 채널·전체 업로드 목록, 저장된 커버 수·표시 조건,
방송·가창 수, 작업 상태와 계정 수집 활성화. 코드 변경은 없으며 fixture 테스트는 실행하지 않았다.
조사 보고서와 커버 checkpoint는 각각 Git 제외
`db-migration/reports/kurokumo-2026-11-07/`, `.tmp/kurokumo-cover-backfill-2026-11-07.json`에 있다.
