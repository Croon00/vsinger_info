## 요구사항

### 기능 요구사항

- FR-001 확인된 song_id 또는 원문 곡명+원곡자 키로 우타와꾸를 묶고 DISTINCT performances.id로 가창 횟수를 센다. 제목만으로 서로 다른 곡을 합치지 않는다.
- FR-002 종류·소속사·복수 아티스트·검색·정렬·영상 게시일을 페이지·total 전에 적용하고 URL과 빈 페이지 total을 보존한다.
- FR-003 커버·발매 음원의 영상 중복·Shorts 대기·미확정 원곡 정책을 적용한다. 저장된 조회수·링크로 재생하고 조회로 provider를 호출하지 않는다.

### 주요 데이터

원본 문서의 아티스트·외부 계정·소유 관계와 해당 기능의 저장 자료·출처·감사 이력을 사용한다. 구체적인 저장 구조와 경로는 plan.md에 연결한다.
