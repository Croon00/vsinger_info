# 오리지널 곡 목록의 발매 커버 제외

작성: 2026-11-25 · 상태: 로컬 구현·실데이터 읽기 확인, 배포 남음

## 사용자 시나리오

- US1: 전제 — 아티스트가 Spotify로 커버 싱글·커버 앨범·라이브 커버 음원을 발매했고 공식 영상은 연결되지 않았다. 동작 — 오리지널 곡 탭이나 아티스트의 오리지널 곡 탭을 연다. 기대 결과 — 그 커버 음원이 오리지널로 보이지 않는다.
- US2: 전제 — 본인·소속 그룹에 크레딧된 곡, 다른 아티스트와 공동 크레딧된 곡, 곡 정보가 없는 녹음이 있다. 동작 — 같은 탭을 연다. 기대 결과 — 모두 기존처럼 오리지널로 보인다.

## 요구사항과 완료 조건

- FR-001: 제목 또는 `version_label`에 단어 `Cover`/`Covered`, `カバー`, `歌ってみた`가 있는 녹음을 오리지널에서 제외한다. 단어 경계를 적용해 `Discover` 같은 곡명은 유지한다.
- FR-002: 곡의 원곡자(`song_artists`)가 있는데 녹음 가창자·가창자의 그룹·멤버 중 누구도 원곡자가 아니면 제외한다. 공동 크레딧은 유지한다.
- FR-003: 곡 연결이나 원곡자가 없는 녹음은 판정하지 않고 유지한다. 발매곡(앨범) 목록·소유권·원본 데이터는 바꾸지 않는다.
- FR-004: 제외는 정렬·총 개수·페이지 계산 전에 적용하며 탐색 오리지널 탭, 아티스트 오리지널 탭, 홈 최근 오리지널에 같은 규칙을 쓴다(`/api/explore/songs?kind=original`).
- SC-001: 기존 오리지널 계약·응답 필드는 유지한다.
- SC-002: 실데이터 전후 비교와 fixture를 기록한다.

근거: 2026-11-25 사용자 요청. 가사 내보내기 중 오리지널 목록에 Spotify 커버 음원이 섞인 것을 확인했다([016](../016-original-lyrics-review/spec.md)).
