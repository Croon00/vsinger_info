# 홈 최근 오리지널·커버 곡

작성: 2026-11-21 · 상태: 로컬 구현·실데이터 조회 확인, 화면 검수 대기

## 사용자 시나리오

- US1: 전제 — 저장된 YouTube 곡이 있다. 동작 — 홈에 접속한다. 기대 결과 — 검색창 아래 오리지널·커버가 게시일 최신순으로 각각 최대 10개 표시된다.
- US2: 전제 — 화면보다 카드가 많다. 동작 — 이동 버튼·가로 스크롤·스와이프로 탐색한다. 기대 결과 — 수동으로 다음 곡을 확인하고 전체 보기로 해당 종류의 최신순 목록에 진입한다.

## 요구사항과 완료 조건

- FR-001: 검색 → 최근 오리지널 → 최근 커버 → 기존 즐겨찾기 순으로 배치한다.
- FR-002: 저장된 분류·YouTube 게시일 기준 각 최대 10개. 기간 하한 없이 유효한 영상 ID가 있고 게시일이 현재 이하인 영상만 사용한다. 미확인·미래 게시일은 제외한다.
- FR-003: 썸네일·두 줄 제목·아티스트·게시일과 기존 영상 다이얼로그를 제공한다.
- FR-004: 자동 이동 없이 버튼·스크롤·스와이프를 제공하고 끝에서는 해당 방향 버튼을 비활성화한다. 키보드 포커스·reduced-motion을 지원한다.
- FR-005: 섹션별 로딩·빈 결과·오류·재시도를 제공한다. 실제 모드에서 목업으로 대체하지 않는다.
- FR-006: 조회만 수행하며 DB 변경·재수집·worker 실행·전송은 시작하지 않는다.
- SC-001: 기본 곡 탐색 계약을 보존하고 새 필터는 페이지 계산 전에 적용한다.
- SC-002: 빌드·HTTP 계약 테스트·실데이터 조회 및 화면 검증의 결과와 한계를 기록한다.
