# YouTube 오리지널 일일 수집

작성 2026-11-22 · 상태: 로컬 구현·fixture 일부 검증, 운영 적용 전

## 사용자 시나리오

- US1: 전제 — 활성 YouTube 계정과 최신 음악 worker가 있다. 동작 — 일일 채널 확인. 기대 결과 — 커버/노래 방송 외 오리지널 후보도 검증한다.
- US2: 전제 — original·official 표기가 없는 영상과 등록 발매 음원이 있다. 동작 — 채널·곡명·버전·길이 비교. 기대 결과 — 유일한 녹음에만 연결하고 기존 링크·명의를 보존한다.
- US3: 전제 — Spotify에 없는 신곡에 오리지널 근거와 등록 가창 명의가 있다. 동작 — 원문·관계 검증. 기대 결과 — 녹음·가창 명의·영상·감사 출처를 저장하고 기존 API로 조회한다.

## 요구사항과 완료 조건

- FR-001 기존 youtube_poll의 YOUTUBE_POLL_INTERVAL_SECONDS(기본 86400초), 최근 최대 200개와 최초 기준선을 재사용한다. 과거 전체 수집은 별도다.
- FR-002 제목 키워드는 필수가 아니다. 등록 음원의 공식 owner 채널·완전한 곡명 필드·버전·길이가 유일하게 일치하면 연결한다. 다른 기존 링크를 덮어쓰거나 이름만으로 병합하지 않는다.
- FR-003 새 녹음은 제목의 명시적 오리지널 곡 표기, 설명의 정확한 originalsong/originalmusic/オリジナル曲 태그 또는 설명 첫 20줄의 현재 곡명을 인용한 오리지널 안내와, 정확한 owner 이름/별칭의 가창 크레딧이 함께 있어야 생성한다. official/MV/Original MV만으로는 생성하지 않으며 미등록 협업자는 보류한다.
- FR-004 커버·예약/진행 방송·노래 방송·티저·Shorts/short.ver/1Chorus/홍보 표기·버전 차이는 제외한다. 90초 미만 또는 길이 미상은 별도 검토한다. 기존 cover/archive와 보관 관계는 재분류하지 않는다.
- FR-005 purpose=original typed 작업과 계정/영상·lease·snapshot·영상별 잠금·기존 연결 확인으로 재실행을 보호한다. 원문·외부 ID·출처 URL·소유권·수동 링크를 보존한다.
- FR-006 미확정 원문은 검토 후보로 남긴다. OpenAI·댓글·Spotify·Discord·Calendar·가사/번역을 추가 호출하지 않는다. 조회 API에서 수집하지 않는다.
- SC-001 기존 cover/archive 작업 키·분류·일일 주기·기준선·조회 계약을 유지한다.
- SC-002 키워드 없는 연결, Spotify 없는 새 곡 생성, 음성 사례·재실행·동시 수정 보호를 검증한다.
- SC-003 로컬 fixture·실데이터 조회·실제 수집·운영 배포를 구분해 기록한다.

추가 화면 요구 FR-007~009, 인수 시나리오·설계·T009~010은 [아티스트 오리지널 곡 목록 확장](ui.md)을 따른다.

등록 발매 음원은 기존 오리지널 탭의 미확정 발매 포함 계약을 유지한다. 영상 연결이 모든 발매의 오리지널 여부를 새로 인증한 뜻은 아니다. 제목/설명 근거도 기존 음원 연결도 없는 영상의 완전 자동 판별은 보장하지 않는다. [상세 계약](../../docs/youtube-original-collection.md).
