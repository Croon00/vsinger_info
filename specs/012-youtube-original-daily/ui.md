# 아티스트 오리지널 곡 목록 확장

2026-11-22 사용자 추가 요청. 기존 발매곡 탭을 곡 단위 목록으로 바꾸며 012 수집 결과의 조회 경로를 완성한다.

- FR-007: 탭 이름을 `오리지널 곡`으로 변경하고 `?tab=originals` 주소를 유지한다. 앨범 없이 YouTube 근거로 등록한 녹음도 아티스트별 목록에 포함한다.
- FR-008: 영상 미연결 곡도 표시한다. 등록 영상만 재생하며, 곡 수·제목 검색·최신 영상/이름/조회수 정렬·24곡 단위 더보기를 제공한다.
- FR-009: 로딩·빈 목록·검색 결과 없음·오류 재시도와 모바일 배치를 지원하고 기존 앨범 직접 링크를 보존한다.
- FR-010: 홈 최근 곡 아래에 즐겨찾기한 아티스트의 오리지널·커버 캐러셀을 각각 둔다. 종류별 YouTube 게시일 최신 10개를 조회하며 즐겨찾기가 없으면 전체 곡으로 대체하지 않는다. 네 캐러셀의 화살표는 썸네일 좌우 중앙에 둔다.

전제 — 아티스트에 앨범 없는 녹음과 영상 미연결 녹음이 등록되어 있다. 동작 — 오리지널 곡 탭 조회, 더보기, 제목 검색, 영상 재생. 기대 결과 — 모든 등록 녹음을 페이지로 탐색하고 영상이 있는 곡만 재생한다. 재생창을 닫으면 실행 버튼으로 포커스를 복원한다.

설계 — `ArtistOriginalSongs.vue`가 기존 `songPage(kind=original, artist_ids=[id])`를 사용한다. `published_only`를 요구하지 않는다. 목록은 기존 ItemGroup/Item, 필터는 기존 입력·Select, 재생은 SongVideoDialog를 사용한다. 요청 변경/해제 시 취소하고 늦게 도착한 더보기 응답을 버린다. 새 HTTP 경로나 수집 호출은 없다.
