## 요구사항

### 기능 요구사항

- FR-001 공식 곡별 소개·버전명·트랙 자료의 명확한 근거로 태그를 부여하고 태그별 출처 URL과 근거를 보존한다.
- FR-002 장르·분위기 복수 선택은 같은 분류 OR·분류 간 AND로 다른 필터와 결합해 페이지·total 전에 적용한다. 다른 종류·미등록 태그 요청은 422다.
- FR-003 공식 영상 ID 또는 recording ID와 곡명·아티스트 조건으로 검수 목록을 연결하고 조회로 수집·자동 분류·DB 변경을 실행하지 않는다.

### 주요 데이터

원본 문서의 아티스트·외부 계정·소유 관계와 해당 기능의 저장 자료·출처·감사 이력을 사용한다. 구체적인 저장 구조와 경로는 plan.md에 연결한다.

## 완료 조건

- SC-001 공개 태그마다 곡·편곡 버전에 맞는 출처가 있으며 미분류 음원은 무필터 목록에 남는다.

AGENTS.md와 프로젝트 원칙, 기존 확정 계약을 따른다. 신규 기능 요구는 추가하지 않았다. 실제 DB 변경·재수집·전송·배포는 개별 요청 범위를 확인한다. Git 제외 보고서는 원본 위치를 참조하며 이번 정리에서 존재·내용을 확인하지 않았다.
