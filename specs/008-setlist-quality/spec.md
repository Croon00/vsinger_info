## 요구사항

### 기능 요구사항

- FR-001 원문·외부 ID·출처·원본 행·추출 버전을 보존하고 가창자 연결에 검수 근거·감사 이력을 남긴다.
- FR-002 완전한 규칙 후보를 우선하고 미확정 후보는 모델 비교·schema·원문 검증을 거친다. 잘못된 시간·후보 충돌·검증 실패를 확정 가창으로 저장하지 않는다.
- FR-003 재시도·재처리에서 기존 가창·수동 크레딧·보관 기록을 보존하고 작업 성공·실제 곡 확보·보류·실패를 구분한다.
- FR-004 명시적 타임스탬프 제목·1부터 연속된 곡 번호·유효 시각·곡정보 구분 구조·종료/하이라이트 경계를 갖춘 목록을 모델 없이 추출한다. 누락 번호·중복/역전 시각·모호한 중간 행·다른 댓글의 충돌은 보류한다. 원곡자 순서가 명시되지 않은 구분자는 곡정보 원문으로 보존한다.
- FR-005 SetList의 곡 번호 파이프 표기·명시적 대화 항목·종료 표기와, 구분선으로 노래 구간이 끝나는 `セトリ＆シーン`을 지원한다. 활성/보관 가창이 이미 있는 방송은 이번 빈 목록 복구에서 변경하지 않는다.

### 주요 데이터

원본 문서의 아티스트·외부 계정·소유 관계와 해당 기능의 저장 자료·출처·감사 이력을 사용한다. 구체적인 저장 구조와 경로는 plan.md에 연결한다.
