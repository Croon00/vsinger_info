# 곡 월드컵(오리지널·커버)

작성: 2026-11-26 · 상태: 로컬 구현·브라우저 검증 완료, 배포 남음

## 사용자 시나리오

- US1: 전제 — 소속사에 공식 MV가 있는 오리지널 곡이 16곡 이상 있다. 동작 — 월드컵 메뉴에서 소속사와 규모를 골라 시작한다. 기대 결과 — 그 소속사 곡만으로 대진이 만들어지고 두 곡씩 양옆에 썸네일·제목·아티스트가 보이며, 들어 보고 한 곡을 고를 수 있다.
- US2: 전제 — 여러 아티스트를 직접 고른다. 동작 — 시작한다. 기대 결과 — 고른 아티스트(승인된 그룹 멤버는 그룹 곡 포함) 곡만 후보가 된다.
- US3: 전제 — 무작위 섞기를 고른다. 동작 — 시작한다. 기대 결과 — 전체 MV 오리지널에서 아티스트별 상한을 두고 무작위로 뽑는다.
- US4: 전제 — 진행 중에 창을 닫았다. 동작 — 다시 월드컵에 들어온다. 기대 결과 — 같은 경기부터 이어서 진행한다. 직전 선택은 되돌릴 수 있다.

## 요구사항과 완료 조건

- FR-001: 후보는 `/api/explore/songs?kind=original&published_only=true`의 공식 MV가 있는 곡이며 영상 ID로 중복을 제거한다. 백엔드 변경 없이 100곡씩 읽는다.
- FR-007: 소속사 선택지는 MV가 있는 오리지널이 16곡 이상인 소속사만 곡 수와 함께 곡 수 내림차순으로 보여 준다(소속사별 `limit=1` 조회로 총계 확인). 없으면 빈 상태를 안내한다.
- FR-011: 아티스트 선택지는 MV가 있는 오리지널이 1곡 이상인 아티스트(승인된 그룹은 그룹 하나)만 곡 수와 함께 보여 준다. MV 오리지널 전체를 한 번 읽어 명의별로 센다(협업 곡은 각 명의에 포함). 선택한 아티스트의 곡 합이 16곡 미만이면 시작 버튼을 비활성화하고 아티스트를 더 고르라고 안내한다.
- FR-012(2026-11-26): 곡 종류(오리지널·커버)를 고른다. 커버는 `kind=cover` 탐색 결과(숏츠 제외 등 기존 커버 규칙)를 쓰고 아티스트는 멤버 명의로 고른다. 통계·랭킹은 종류별로 분리한다. 설정 화면의 소속사·아티스트 곡 수는 `/api/worldcup/pool-summary` 한 번으로 받는다. 2,000곡 초과 후보는 무작위 페이지 표본을 쓴다.
- FR-002: 규모는 16·32·64·128강(기본 32강). 후보 수보다 큰 규모는 비활성화한다. 후보 뽑기는 무작위 또는 조회수 상위.
- FR-003: 첫 라운드는 같은 아티스트끼리 만나지 않도록 배치한다(가능한 경우). 무작위 섞기는 아티스트당 max(2, 규모/8)곡 상한을 두고 부족하면 완화한다.
- FR-004: 대결 화면은 진행(라운드, 경기 번호, 전체 진행 막대), 되돌리기, 그만두기를 제공한다. 썸네일을 누르면 그 자리에서 YouTube 임베드를 재생한다. 음원을 내려받지 않는다.
- FR-005: 결과 화면은 우승·준우승·4강·8강을 보여 주고 YouTube 링크와 새 월드컵을 제공한다.
- FR-006: 진행 상태는 브라우저 localStorage에 저장한다. 저장소를 쓸 수 없으면 이어하기 없이 진행한다.
- FR-008(2026-11-26 추가): 끝까지 마친 판만 서버에 한 번 제출한다(제출 ID로 중복 방지). 서버는 대진 구조·속도·공식 MV 여부·제출 빈도를 검증한다. 익명 브라우저 ID 외 개인 정보는 저장하지 않는다.
- FR-009: 곡별 우승 횟수·우승 비율(우승÷출전)·1:1 승률을 결과 화면과 랭킹 탭(전체·소속사, 정렬 3종, 비율은 3판 이상)에서 보여 준다.
- FR-010: 로컬 개발 프록시에서 제출한 판은 공개 통계에서 제외한다.
- SC-001: 대진·진행·되돌리기·결과 순위 단위 테스트와 브라우저 통합 테스트를 기록한다.

근거: 2026-11-25~26 사용자 요청(그룹·아티스트·무작위 선택, MV 양옆 재생·선택, 128강까지).
