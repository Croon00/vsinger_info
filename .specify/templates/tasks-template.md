# 작업 목록 — [기능 이름]

입력 문서는 spec.md·plan.md 및 관련 research.md·data-model.md·contracts/다.
한국어로 작성하고 작업 ID·US·FR/SC·실제 파일 경로를 연결한다.

## 작성 방법

- 작업 형식은 `- [ ] T001 [US1] 구체적인 작업과 파일 경로. FR-001, SC-001.`을 따른다.
- 독립적인 작업에만 [P]를 붙인다. 에이전트 위임은 적용 지침과 사용자 요청을 따른다.
- 요구사항의 우선순위와 실제 의존성 순으로 배치한다.
- 기존 테스트를 우선 사용하고 변경에 맞는 검증을 포함한다.
- 과거 완료 근거를 기록하고 이번 작업에서 검증한 항목의 완료 상태를 갱신한다.
- 아래 예시는 실제 기능 작업으로 교체한다.
