# Front Design Draft

이 디렉터리는 `schedule_music`의 독립적인 프론트 디자인 테스트 프로젝트다.

## 작업 범위

- 새 프론트의 파일과 의존성은 이 디렉터리에 둔다.
- 기존 `../web`의 화면, 스타일, 컴포넌트, 레이아웃을 읽어 디자인 참고로 삼거나 재사용하지 않는다.
- 기존 백엔드는 API 경로, 요청 파라미터, 응답 스키마 확인에만 참고한다. 서버를 실행하거나 DB에 연결하지 않는다.
- 앱 데이터는 mock API로 제공한다. 실제 YouTube 임베드 재생과 공식 이미지 표시는 허용한다.
- 사용자 판단과 화면별 설계는 `docs/design-plan.md`를 따른다.

## 설치된 프로젝트 스킬

1. `.agents/skills/shadcn-vue/SKILL.md`
2. `.agents/skills/transitions-dev/SKILL.md`

두 스킬의 지침이 겹치면 **shadcn-vue를 우선**한다. 컴포넌트 구조, 접근성, 색상, 폰트, 반경, 아이콘은 shadcn-vue를 따른다. transitions-dev는 호환되는 동작과 모션 토큰에 사용한다. 별도의 모달/탭 시스템이나 디자인 테마로 대체하지 않는다.

## 디자인 기반

- Vue + TypeScript + Vite 기반 독립 앱을 계획한다.
- shadcn-vue 초기화 시 반드시 `--preset a2vfHFI`를 CLI에 전달한다. 수동으로 유사한 CSS를 작성해 프리셋 적용을 대신하지 않는다.
- 실제 CLI가 생성한 `components.json`과 전역 CSS를 기준으로 삼는다.
- 테마는 기기 설정을 기본으로 따르고 설정 화면에서 시스템/라이트/다크를 선택할 수 있다.
- 메뉴는 홈, 탐색, 캘린더, 설정 네 개다. PC는 좌측 사이드바, 모바일은 하단 독 형태다.
- 통합검색 대상은 아티스트 이름과 세트리스트의 원곡명·원곡 아티스트명이다. 세트리스트 검색 결과는 해당 라이브의 노래 시작 시점으로 연결한다.
- 캘린더에는 오프라인 공연과 생일만 표시한다.
- 라이브 뷰어는 YouTube 영상과 타임스탬프별 세트리스트를 제공한다. 곡 선택 시 해당 시점으로 이동한다.
- 실제 아티스트 이름과 공식 프로필 이미지를 사용하고, 가상 일정과 샘플 가사는 실제 자료와 구분한다.
- 가사는 직접 작성한 예시 문구로 준비하고 실제 곡의 가사인 것처럼 표시하지 않는다.
- 외부 티켓 링크 열기만 지원한다. 구매나 응모 자동화는 범위에 없다.

사용자의 구현 시작 승인에 따라 독립 앱을 구현했다. 후속 수정도 이 문서와 `docs/design-plan.md`의 범위를 유지한다. 실행과 검증 방법은 `README.md`를 따른다.
