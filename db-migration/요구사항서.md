# 관리자 웹 도구 요구사항서

## 1. 목적
* 새로운 DB에 들어갈 초기 데이터(아티스트, 곡, 라이브, 공연 등)를 안전하게 검토하고 적재한다.
* 초기 구축 이후에도 새로운 데이터를 지속적으로 등록하고 관리하는 전용 도구로 활용한다.
* 별도의 외부 서버 없이 로컬 환경에서만 안전하게 동작한다.

---

## 2. 핵심 워크플로우 (2가지 입력 방식)

### ① AI 정제 기반 반자동 검토 (File Drop & Review)
1. **AI 정제 요청**: 초기 데이터나 추가할 데이터의 정제를 AI에게 요청하여 정해진 포맷(JSON) 파일로 생성한다.
2. **폴더 투입**: 생성된 JSON 파일들을 `input/` 폴더에 넣는다.
3. **웹 화면 검토**: 웹사이트에서 `input/` 폴더의 데이터를 불러와 순서대로 내용을 확인하고 필요 시 수정한다.
4. **DB 전송**: 검토 및 승인이 완료되면 버튼을 눌러 DB 서버에 전송(저장)한다.

### ② 완전 수동 등록 (Manual Entry)
* 웹사이트에서 **[추가]** 버튼을 눌러 입력 폼을 띄우고, 사람이 직접 타이핑하여 작성한 뒤 DB에 즉시 등록한다.
